# מה רואים? (ma-roim)

פותח על ידי צביקה הרמתי.

מרימים את הטלפון לכיוון הנוף ומקבלים על תמונת המצלמה את שמות ההרים, היישובים ונקודות הציון שרואים משם, בדומה לאפליקציות של מפת כוכבים.

כרגע זה אב-טיפוס ווב (PWA) שרץ ב-Chrome באנדרואיד, בלי שום התקנה. אם הוא יעבוד טוב בשטח, השלב הבא הוא אפליקציית אנדרואיד מלאה.

## איך זה עובד
- **מיקום:** GPS (`navigator.geolocation`).
- **כיוון הטלפון:** `AbsoluteOrientationSensor` (מצפן ומד תאוצה ביחד). אם הוא לא זמין, נעשה שימוש באירוע `deviceorientationabsolute`.
- **מקומות:** שאילתה ל-OpenStreetMap דרך Overpass API: ערים ועיירות עד 90 ק״מ, יישובים עד 35 ק״מ, פסגות והרי געש עד 60 ק״מ, ואגמים ועמקים בעלי ערך ויקידאטה. השמות מוצגים בעברית כשיש `name:he`. התוצאה נשמרת בדפדפן.
- **גבהים:** AWS Terrain Tiles (בקידוד Terrarium, משולב מ-SRTM ומקורות נוספים) בשתי רזולוציות. מהם מחושבים:
  - גובה הצופה;
  - **קו ראייה**: יישוב שמוסתר מאחורי הר לא מוצג;
  - **קו רכס** (הקו הצהוב), שעוזר לכייל את המצפן.
- **הקרנה:** אזימוט וזווית גובה לכל נקודה, כולל עקמומיות כדור הארץ ושבירת אור. משם מחשבים קואורדינטות במסגרת הטלפון ואז פיקסלים על המסך לפי שדה הראייה של המצלמה.
- **סינון:** לכל מקום יש ציון חשיבות (סוג, אוכלוסייה, גובה, ויקידאטה). כל ציון קובע עד איזה מרחק המקום מוצג, והטווח הזה גדל עם הזום. התוויות מסודרות בשורות בלי חפיפה.

## שימוש
- **גרירה אופקית או אנכית:** תיקון המצפן או הנטייה. התיקון נשמר. ⟲ מאפס אותו.
- **צביטה:** זום, ובזום מופיעים גם מקומות קטנים ורחוקים יותר.
- **לחיצה על תווית:** פרטים, קישור לוויקיפדיה ולמפה.
- **⚙:** שדה ראייה, צפיפות תוויות, הצגת מקומות מוסתרים וקו הרכס.
- **מצב הדגמה לבדיקות:** `?demo=1&lat=33.0918&lon=35.5612&h=40`.

## נתונים ו-APK
ה-workflow `.github/workflows/build.yml` רץ בכל push:
1. מוריד מחדש מ-OpenStreetMap את `data/landmarks.json` ואת `data/roads.json` (כבישים ממוספרים, נקודה כל כ-600 מ׳), כש-`tools/build_landmarks.py` משתנה או כשמפעילים אותו ידנית.
2. בונה APK עם Capacitor (`tools/build_apk.sh`) ומפרסם אותו כ-release בשם `apk-latest`.

## הרצה מקומית
```
python3 -m http.server 8000
```
ואז לפתוח את http://localhost:8000/?demo=1.
מצלמה ו-GPS בטלפון דורשים HTTPS, למשל GitHub Pages.
